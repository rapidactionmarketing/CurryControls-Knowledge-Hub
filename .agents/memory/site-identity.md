# Site identity, ownership, and disclaimer wording

**The factual record** (never extend it): Curry Controls Company was acquired by Revere Control Systems, Inc. in 2021. Eric Sullivan was formerly employed by Curry Controls Company (he worked with the company for more than 25 years); that employment ended in 2021. A prior registration of CurryControls.com expired, completed the deletion process, and became publicly available; Eric Sullivan independently registered the domain in 2025 (registry creation date April 13, 2025) in his individual capacity. The current registration is a new registration, not a transfer from any prior registrant, and the site never names the prior registrant. The current website is new content managed and published by Eric Sullivan. He is currently employed by General Control Systems, Inc., which is separate from the site. CurryControls.com is not owned, operated, sponsored, endorsed, maintained, authorized, or published by Curry Controls Company, Revere Control Systems, Inc., S.J. Electro Systems, LLC, or General Control Systems, Inc. The telephone number is Eric's own.

**Prohibited:** any succession wording ("now GCS", "became GCS", "legacy continues", "successor company", "same company"), any wording that the domain was acquired, purchased, or transferred from a prior registrant, "everything on this site belongs to Eric" (it would sweep in third-party trademarks, standards, quotations, open-source code), and "original site content". Do not state or imply that General Control Systems acquired or succeeded Curry Controls Company.

**Where the wording lives:** `artifacts/currycontrols/src/data/site-legal.ts`. `siteIdentity` holds the facts; `LEGAL` holds every derived statement (full ownership statement, popup, footer, contact, About Eric, project, metadata, home, AI crawler) and every technical notice (calculator result, programming example, troubleshooting, code and standard, manufacturer, reference table, safety, use at own risk, external links, no professional relationship) plus the full Information & Calculator Disclaimer sections. `src/data/site.ts` only derives `SITE.description`, `CONTACT`, and the short `DISCLAIMERS` from it. The notice (`notice-gate.tsx`), home, `/about/site`, `/about/ownership`, `/about/eric-sullivan`, `/terms`, `/disclaimer`, `/privacy`, `/editorial-standards`, the footer, `/contact`, the project pages, the calculator and article templates, `structured-data.ts`, and `build-seo.mjs` (llms.txt) all render from it. Never write a second version of any statement; change the constant. A sentence ending with a name that ends in "Inc." takes no extra period.

**Tests:** `pnpm --filter @workspace/currycontrols test` runs `src/__tests__/legal.test.tsx`, which checks the popup, footer, contact, calculator, programming, llms.txt, structured data, metadata, project pages, and scans the source for prohibited phrases.
